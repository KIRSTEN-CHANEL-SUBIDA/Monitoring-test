# FAct2: Smart Equipment Monitoring and Diagnostic System

## Group
- Group: Group 1
- Members: Member 1, Member 2, Member 3, Member 4

## Description
A simple program that asks for equipment temperature, voltage, and communication status, then classifies the equipment as NORMAL, WARNING, or CRITICAL. It repeats until the user enters -1, then shows a summary.

## How to Run
- Python: `python equipment_monitor.py`
- Java: `javac EquipmentMonitor.java` then `java EquipmentMonitor`
- C++: `g++ equipment_monitor.cpp -o equipment_monitor` then `./equipment_monitor`
